String & String Handling

# String 
  A String is an object in Java that represents a sequence of characters.
  Syntax : String name = "Khushi";(String Literal)

# String pool 
 The String Pool is a special area associated with the Java heap where Java maintains and reuses canonical String instances.Its main purpose is to avoid creating unnecessary duplicate String objects for identical String literals.

# Immutability 
 Immutability means that an object's state cannot be changed after the object has been created.

# StringBuilder 
 Mutable and generally preferred for repeated text modifications in single-threaded code.

# StringBuffer 
 Mutable and synchronizes its methods for thread-safe individual operations.

# Common String methods
 length(), charAt(), toUpperCase(), toLowerCase(), subString(), contains(), trim(), split(), equals(), equalsIgnoreCase(), indexOf(), replace(), isEmpty().
